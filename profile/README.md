# Performance

Performance depends on document complexity, number of objects, effects, fonts, linked or embedded images, available memory, graphics hardware, and storage speed.

Organized layers, optimized images, and sufficient RAM can improve responsiveness when working with large design projects.

---

# Troubleshooting

If CorelDRAW becomes slow or unstable, review document complexity, installed fonts, graphics drivers, imported assets, available memory, and recently added extensions or customizations.

For output problems, verify document dimensions, color mode, fonts, bleed settings, image resolution, and export configuration.

Maintain backup copies and incremental versions of important design files.
